# 📊 Online Retail Data Analysis (Power BI Project)

## 📌 Project Overview
This project analyzes an online retail dataset to extract meaningful business insights using Power BI.

## 🔧 Tools Used
- Power BI
- Data Cleaning & Transformation

## 🧹 Data Cleaning
- Removed records where Quantity < 1
- Removed records where Unit Price < 0
- Created Revenue column (Quantity × Unit Price)

## 📈 Key Analysis

### 1. Revenue Trend (2011)
- Identified seasonal trends using a line chart

### 2. Top Countries
- Found top 10 countries by revenue (excluding UK)

### 3. Top Customers
- Identified top 10 revenue-generating customers

### 4. Demand by Region
- Used map visualization to analyze demand across countries

## 💡 Key Insights
- Revenue peaks during year-end (seasonal demand)
- Few countries contribute most revenue
- High-value customers drive business growth
- Certain regions show strong demand (expansion opportunity)
